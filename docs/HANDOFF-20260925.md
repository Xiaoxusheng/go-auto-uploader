## 五、踩坑速查（详见 spatial-de.md 与用户级 MEMORY.md）

- 服务器重启进程**必须 cd /home/upload**（相对路径全偏 = "主播数据没来"）
- Windows 中文路径 cv2 用 imdecode；gcc 需要 ASCII TMP（TMP=D:\upload\_vendor\tmp）
- cgo 构建需 `CGO_ENABLED=1 CC=D:/upload/_vendor/mingw64/mingw64/bin/gcc.exe`
- onnxruntime_go v1.36 配 ORT 1.30（API 29）；ORT 1.20 会报 API 版本不支持
- 本机 IPv6 会周期性掉（全球地址过期）——服务器失联先查本机 v6，等 RA 自愈或重启路由器
- scp 管道在隧道上会坏：大文件用 base64-over-ssh + MD5 校验
